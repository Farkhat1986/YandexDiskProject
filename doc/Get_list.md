# Для реализации автотестов API Диска необходимо:

1. Авторизоваться в Яндекс Диске
2. Перейти в Полигон по ссылке: https://yandex.ru/dev/disk/poligon/
3. Получчить токен, нажав на кнопку "Получить OAuth-токен"

Базовый URL для запросов: https://cloud-api.yandex.net

Полученный токен (ayth_token) должен быть указан в заголовках (Headers) при каждом
запросе, если не указано иное: {Authorization: OAuth auth_token}

## Получение списка файлов

**Предусловие:**
 * Создана временная папка на Яндекс Диске
 * В папку загружен хотя бы один тестовый файл
 * Получен валидный OAuth-токен для авторизации

**Шаги:**
1. Отправить GET запрос на получение списка файлов в папке /v1/disk/resources с параметром path={folder_path} 

**Ожидаемые результаты:**
 * Код ответа 200 ОК
 * Тело ответа содержит поле "type": "dir"
 * Тело ответа содержит поле "_embedded" с массивом файлов 

2. Проверить структуру ответа через JSON Schema

**Ожидаемые результаты:**
* Ответ соответствует JSON Schema, сгенерированной из Pydantic модели FilesListResponse
* Все обязательные поля присутствуют в ответе
* Типы данных всех полей соответствуют схеме

3. Проверить ответ через Pydantic модел

**Ожидаемые результаты:**
* Модель FilesListResponse успешно валидирует ответ
* В массиве items содержится хотя бы один файл
* Загруженный тестовый файл присутствует в списке файлов


## Тест кейс 2: Валидация структуры папки через JSON Schema

**Предусловие:**
 * Убедиться, что на Диске есть папка с файлами
 * Имеется валидный OAuth-токен

**Шаги:**
1. Отправить GET запрос на получение информации о папке /v1/disk/resources с параметром path={folder_path}

**Ожидаемые результаты:**
* Код ответа 200 OK
* Ответ содержит корректную структуру папки согласно JSON Schema

2. Проверить обязательные поля ответа:

**Ожидаемые результаты:**

*Присутствуют все обязательные поля согласно схеме

* Поле "type" имеет значение "dir"

* Поле "_embedded" содержит массив элементов

* Каждый элемент массива имеет обязательные поля: name, path, type

## Тест кейс 3: Проверка наличия конкретного файла в списке

**Предусловие:**
 * Создана тестовая папка
 * Загружен конкретный файл с известным именем
 * Имеется валидный OAuth-токен

**Шаги:**
1. Отправить GET запрос на получение списка файлов в папке

**Ожидаемые результаты:**
 * Код ответа 200 OK

 * Ответ успешно проходит валидацию через Pydantic модель


2. Найти загруженный файл в массиве items

**Ожидаемые результаты:**

* Файл с ожидаемым именем присутствует в списке

* Поле name файла соответствует имени загруженного файла

* Поле type файла имеет значение "file"


## Тест кейс 4: Валидация ответа при запросе несуществующей папки

**Предусловие:**
* Папка с указанным путем не существует на Яндекс Диске
* Имеется валидный OAuth-токен

**Шаги:**
1. Отправить GET запрос на получение списка файлов в несуществующей папке

**Ожидаемые результаты:**
* Код ответа 404 Not Found
* Запрос не проходит валидацию через JSON Schema для успешного ответа

## Тест кейс 5: Валидация ответа при запросе файла

**Предусловие:**
* Существует файл на Яндекс Диске
* Имеется валидный OAuth-токен

**Шаги:**
1. Отправить GET запрос на получение информации о файле (указать путь к файлу)

**Ожидаемые результаты:**
* Код ответа 200 OK
* Ответ не содержит поле "_embedded"
* Поле "type" имеет значение "file"
* Ответ не проходит полную валидацию через схему для списка файлов папки
